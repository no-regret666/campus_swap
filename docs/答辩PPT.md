## 第3页：选题背景

### 为什么要做这个系统？

**真实校园场景：**
- 毕业季、换宿舍时，大量闲置物品（教材、生活用品、电子设备）被丢弃
- 学生有短期技能服务需求（电脑维修、摄影、乐器教学）
- 传统二手交易以现金买卖为主，缺少校园内的"以物换物"渠道

**课程要求：**
- 避开商城、外卖、教学、酒店、图书等禁用题目
- 系统需包含不少于 8 张数据表、6 个功能模块

## 第4页：应用场景

### 系统解决什么问题？

| 场景 | 需求 | 系统方案 |
|------|------|----------|
| 毕业清理 | 教材、生活用品闲置 | 发布物品，寻找交换对象 |
| 技能互助 | 修电脑、拍照、教乐器 | 发布技能服务，技能换物 |
| 换宿舍 | 床帘、收纳盒等不匹配 | 同城校区内安全面交 |
| 社团活动 | 临时道具、服装需求 | 短期借用，无需购买 |

## 第5页：系统功能模块（10个）

### 核心功能一览

1. **用户认证** — 学生登录/注册，JWT无状态认证，管理员角色区分
2. **闲置物品发布** — 发布物品或技能服务，填写分类、成色、期望交换内容
3. **闲置广场检索** — 关键词搜索、分类/校区筛选，瀑布流卡片布局
4. **交换申请管理** — 发起申请 → 物主同意/拒绝 → 双方完成交换
5. **站内消息沟通** — 围绕交换的实时聊天，气泡样式，保留完整记录
6. **收藏与智能推荐** — 收藏物品，按收藏偏好个性化推荐
7. **信用评价** — 交换完成后 1-5 分互评，影响用户信用分
8. **举报与审核** — 违规物品举报，管理员后台处理
9. **后台运营看板** — 用户数、物品数、交换数、热门分类统计
10. **移动端适配** — 响应式布局，手机浏览器可用

## 第6页：技术选型

### 前后端分离架构

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端** | Vue 3 + Vite + Pinia | 响应式框架，Composition API，状态管理 |
| **路由** | Vue Router | 单页应用路由，支持路由守卫 |
| **通信** | Axios + RESTful API | HTTP请求封装，前后端分离 |
| **后端** | Go 1.21 + Gin | 高性能HTTP框架，中间件支持 |
| **认证** | JWT Bearer Token | 无状态认证，支持Token过期续期 |
| **数据** | JSON文件存储（演示版） | 自动持久化，可扩展至MySQL |
| **版本控制** | Git | 分支管理，多人协作 |

## 第7页：系统架构

### 前后端分离 + RESTful API

```
┌──────────────────┐      ┌──────────────────┐
│   Vue 3 前端      │      │   Go Gin 后端     │
│  (localhost:3000)│◄────►│  (localhost:8080)│
│                  │  HTTP│                  │
│ • Views/Components│ API │ • Handler       │
│ • Pinia Store     │      │ • JWT Middleware │
│ • Axios API层    │      │ • Service (JSON) │
│ • Router        │      │                 │
└──────────────────┘      └──────────────────┘
```

- Vite 开发服务器代理 `/api` 到后端 8080 端口
- JWT Token 存储于 localStorage，请求头携带 `Authorization: Bearer <token>`
- CORS 中间件支持跨域开发

## 第13页：项目创新点

### 与传统二手交易系统的区别

| 创新点 | 说明 |
|--------|------|
| **以物换物** | 不以现金买卖为核心，强调校园内的物品互换 |
| **技能互助** | 支持"技能服务"分类，用技能换物品或服务 |
| **信用体系** | 1-5 分互评，信用分影响展示优先级，约束用户行为 |
| **安全面交** | 交换流程内置"面交地点/时间"字段，强调线下安全交易 |
| **收藏驱动推荐** | 根据用户收藏的分类偏好，个性化推荐相似物品 |
| **低碳校园理念** | 减少浪费，提高资源循环利用率，符合校园环保主题 |

## 第17页：技术特色总结

### 项目技术亮点

1. **前后端分离** — Go Gin + Vue 3，RESTful API 通信，职责清晰
2. **JWT 无状态认证** — 中间件鉴权，Token 自动续期，安全性高
3. **响应式设计** — PC/平板/手机多端适配，移动优先
4. **模块化开发** — 5人并行，Git分支管理，零代码冲突
5. **数据持久化** — JSON文件自动读写，演示版开箱即用，可扩展MySQL
6. **完整闭环** — 发布 → 浏览 → 交换 → 评价，业务流程完整
