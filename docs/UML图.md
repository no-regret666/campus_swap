## 四、活动图

### 4.1 用户注册登录流程

```
开始
  │
  ▼
用户是否登录？
  │
  ├──是───> 进入首页
  │
  └──否───> 选择登录/注册
            │
            ├──登录───> 输入账号密码
            │             │
            │             ▼
            │         验证成功？
            │           │
            │           ├──是───> 进入首页
            │           │
            │           └──否───> 提示错误，返回重新输入
            │
            └──注册───> 输入注册信息
                        │
                        ▼
                    验证通过？
                      │
                      ├──是───> 创建用户，进入首页
                      │
                      └──否───> 提示错误，返回重新输入
```

### 4.2 物品发布流程

```
开始
  │
  ▼
填写物品基本信息
  │
  ▼
上传图片
  │
  ▼
图片上传成功？
  │
  ├──否───> 提示错误，重新上传
  │
  └──是───> 确认发布？
            │
            ├──否───> 返回修改
            │
            └──是───> 提交发布
                      │
                      ▼
                  发布成功
                      │
                      ▼
                    结束
```

### 4.3 交换流程

```
开始
  │
  ▼
浏览物品
  │
  ▼
选择目标物品
  │
  ▼
发起交换申请
  │
  ▼
物主是否同意？
  │
  ├──否───> 交换结束（已拒绝）
  │
  └──是───> 协商面交时间地点
            │
            ▼
        完成面交？
          │
          ├──否───> 继续协商或取消
          │
          └──是───> 双方评价
                    │
                    ▼
                交换完成
                    │
                    ▼
                  结束
```
